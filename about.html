About Online Compiler

Online Compiler is a free online code editor that works directly in your browser. There is nothing to install and no account to create. Open the page, write your code and run it.

What you can do

Write and run Python code (including simple programs that ask for input and graphs made with matplotlib), and build web pages with HTML, CSS and JavaScript with a live preview. The editor is based on the same editing engine used by popular desktop code editors, with syntax colouring, code suggestions and a Problems panel that points out mistakes in your code.

Your files stay with you

Your projects are saved in your own browser on your own device. Your code is not uploaded to our servers. You can also download any file with one click.

Who we are

Online Compiler is built and maintained by the Zikim team for students, beginners and anyone who wants to practise coding quickly on any computer.
